## 五、视觉与布局参考

### 5.1 小程序

原型总体采用蓝色主操作、浅色背景、白色卡片、分组表单、横向方案标签和底部固定操作。最新版登录为浅蓝背景、品牌 Logo、手机号按钮及底部协议；首页/我的具有底部双入口导航。产品介绍和投保页较长，主要按钮需保持可达。

当前代码的具体颜色与尺寸来自页面 CSS，并非原型导出的正式设计变量。例如主色可见 `#2d91e8`、`#3ba4e8`，全局背景 `#e9f9ff`，首页后续样式背景 `#f5f8fc`。现有文件有后置样式覆盖，核对视觉时应使用最终样式计算结果。

- 750 是 Taro 设计宽度，尺寸转换由构建完成；页面源码数字并非真机物理像素。
- 自定义头部保留状态栏和原生胶囊空间；底部使用安全区内边距。
- 固定底栏需要正文预留空间，避免遮挡最后一项或协议。
- 费用、责任、协议和阅读采用遮罩浮层/抽屉；长内容需能滚动，关闭和下一步入口保持可见。
- 状态不能只靠颜色表达，还应有“待支付”“退款中”等文字。

### 5.2 PC 管理后台

原型采用左侧深色菜单、顶部导航/面包屑、标签、筛选区、表格/分页、配置页签、富文本和弹窗。代码使用 Element Plus，默认主题 `#409EFF`、左侧布局、固定头部和页签；产品配置有浅蓝分组块，内容容器最大宽度 1180px。

列表需要横向展示较多字段，并保留右侧操作列；订单详情使用右侧抽屉，当前代码窄屏时占满宽度。图片和文件错误应在上传区域附近展示，保存过程中避免重复提交。
