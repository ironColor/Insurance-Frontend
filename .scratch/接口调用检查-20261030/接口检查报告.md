## 结果的适用范围

- PC 的 36 个接口全部返回 HTTP 200，但响应体业务 `code=401`、`msg=未能读取到有效 token`，不能计为业务成功。小程序另有 12 个接口返回鉴权失败。
- 48 个鉴权响应只能确认认证层有响应；必须携带合法登录身份后才能确认具体路由、权限和业务功能。
- 小程序 `/login` 的空请求体返回业务 `code=400`，证明参数校验处理可达；未提供有效微信 `xcxCode`，未验证真实登录。
- 小程序两个产品查询使用明确无效的 ID，扫码解析使用明确无效的 scene，均返回业务 `code=500` 和参数相关提示。这些是探测参数引起的响应，不能据此认定后端业务故障。需真实产品 ID 和扫码参数复测。
- `GET /pay/cancelOrder/{orderNo}` 会取消订单，本次未执行。支付、退款、资料更新、新增、保存、上传和删除仅做无登录、无业务请求体或非法类型 ID 的校验检查，未验证其业务成功。
- `/user/phone` 未携带 `phoneCode`，没有消费微信手机号授权码。退出接口未携带任何用户会话。
- 查询详情使用无效参数，不读取其他用户资料或真实订单。
- 两份文档未配置 OpenAPI 的 `security/securitySchemes`，但描述含登录或权限要求，不能据此视为匿名接口。
- 文档 `servers` 指向内网，本次使用公网网关前缀。PC：`https://www.zfxbaoxian.com/prod-api/product`；小程序：`https://www.zfxbaoxian.com/prod-api/wxmini`，均在前缀后追加文档路径。

## 继续验证所需条件

PC 需要有对应业务权限的测试登录身份；小程序需要通过正常微信登录取得测试会话。产品查询与扫码解析需要真实产品 ID、有效 scene；订单相关需要属于该测试用户的测试订单。支付、退款、删除等完整业务验证需要可供操作的测试数据与环境。

本次未使用登录令牌，未保存用户资料、订单内容或支付配置；检查明细仅保留响应状态与数据条数等元信息。

## 小程序微信支付文档核对

文档已定义小程序微信支付能力，实际商户配置与支付成功尚未验证。

| 环节 | 接口 | 文档能力 |
| --- | --- | --- |
| 支付前校验 | `POST /pay/validBeforePay` | 校验投保业务参数 |
| 预下单 | `POST /pay/prepay` | 保存订单并返回微信支付参数 |
| 订单查询 | `GET /order/{orderId}`、`GET /order/getOrderByOrderNo/{orderNo}` | 查询服务端订单详情与状态 |
| 退款申请 | `POST /pay/applyRefund` | 申请退款并返回处理结果 |

`PayRequestDTO.method="4"` 明确代表小程序支付。`PayResponseDTO` 包含 `timeStamp`、`nonceStr`、`packageStr`、`signType`、`paySign` 等字段，接入时需将 `packageStr` 映射为 `wx.requestPayment` 或 `Taro.requestPayment` 的 `package` 参数，并同时检查外层 `code` 和内层 `success/errorCode/errorMsg`。

当前前端 `src/pages/payment/index.tsx:67` 的确认按钮仅弹出“支付暂不可用”，未接入预下单或微信支付调用。

接入前需补充确认：支付金额 `amount` 的单位；`orderData` 字符串中投保数据的结构；支付回调处理、订单状态枚举及查询结果如何确认支付成功。文档中出现 `notifyUrl`，但本份文档未列出回调处理端点与状态更新契约，不能据此确认后端回调已正常工作。

微信官方要求使用服务端签名参数调起支付，最终支付结果以后端查询和支付成功通知为准。参考：[微信支付小程序调起支付文档](https://pay.wechatpay.cn/doc/v3/merchant/4012791898)。

## PC 登录补充验证

使用用户提供的测试身份，按正常验证码流程仅尝试一次登录。验证码通过后，服务返回 HTTP 200、业务 `code=500`、提示“密码输入错误1次”。未取得令牌，未继续尝试其他密码。

因此，PC 14 个查询接口仍缺少登录后验证；22 个新增、保存、修改、删除及二维码生成接口未执行认证后业务请求。

自动审批拒绝了登录后使用无效参数探测写接口的方案，理由是生产接口即使使用无效参数，也不能保证不会发生真实数据变更。已改为仅计划正常登录和查询，未执行被拒绝的写请求。后续完整写功能验证需要可供操作的测试环境及测试数据。

本报告未记录账号密码或登录令牌。单独验证结果见同目录 `PC登录验证结果.json`。
